# Demo.2 实际范围

版本 **0.7.0-demo.2**。在demo.1的实际源码上增量开发；不是又一版设计文档，也不是V0.7全功能完成版。

## 已实现且本轮有实际运行

保留：两个Go程序、SQLite WAL/FTS5、MD/TXT导入、文件edition发布、编号与词法、范围句柄与缓存分页、原文读取、有出处的明确标注关系、草稿与发布、四角色/KB Key、后台任务、MCP工具子集、只读local Client、工作台。

新增：
- **Git来源**：本机仓库固定提交完整枚举，不读工作区未提交文件；改名/移除/新增更新，旧引用仍可读。
- **自动构建**：显式每来源定时检查、目录内容轮询/去抖、签名Hook，均只入同一任务队列。默认关闭。
- **来源/任务状态**：来源检查与成功时间、Git修订、逐文件结果、触发原因、已有模型用量详情。
- **小题集评测**：人工预期、固定file版、显式策略、TopK资料命中、负例、配对差异、逐题trace。不是业务全量统计评测。
- **诊断入口**：保留有界真实query摘要，CLI与界面读取不重新执行；不保存全文隐藏思考。
- **真实界面**：来源新增/策略编辑、评测导入/运行/报告、任务细节、编辑已有知识草稿。
- **旧数据升级**：原demo.1临时数据实测，保持原Key/ref/正文，新增表可重复打开。

## 代码已存在，但不扩大测试结论

Embedding/Rerank/Chat、Qdrant REST、Neo4j Query API和direct继续用受控HTTP端点测试；JSONL抽取器执行真实本地进程。没有真实商业模型、Neo4j/Cypher和Qdrant实例联合运行。

Git公共HTTPS镜像缓存分支已编码，本轮没有外网Git远程现场测试；实际使用实验为本机仓库。HTTP Hook是XRAG自定义HMAC协议，不能称已兼容GitHub/GitLab原生回调。

## 当前限制

| 项目 | 当前边界 |
|---|---|
| 解析 | 字符/双字词项、保守标题分块、JSON配置；非完整YAML/CommonMark；无PDF/Office/OCR |
| 来源 | path/builtin/git；无OSS/WeKnora；Git不处理LFS正文、子模块、私有远程凭据 |
| 自动检查 | 秒级间隔与内容轮询；非cron、非fsnotify；串行来源扫描，慢来源影响后续检查 |
| 扫描规模 | 单来源5000支持文件、单文件5MiB、总正文64MiB；全量成功后才移除缺席文件 |
| 模型与投影 | 配置能力失败时保持旧文件版；未做完整代号迁移和后端补偿GC |
| 图 | 默认明确标注或显式抽取插件，不声称LLM自动识别问题；Neo4j联调未做 |
| 评测 | 单KB、最多100题×5策略、固定文件版/小题集；其他库FTS全局词频及外部模型无法完全冻结 |
| 费用 | 构建/wiki保留已有call known/unknown记录；新评测的查询没有完整token/金额预算，不虚构成本 |
| 草稿/Wiki | 手工草稿编辑/发布可用；Wiki仍为配置Chat后的单次固定生成，未做再生成/同步写回 |
| 任务 | 排队24h、首次执行起算10min，旧租约失败需显式重提；自动来源下次扫描可产生新的构建，不是透明续跑 |
| 历史与GC | 引用文件版仍长期保留；查询摘要最多2000条/7天；其它任务/评测数据暂无完整GC |
| 部署 | 单机SQLite；不支持网络盘作元数据库、多机器Server集群或生产SLA |
| MCP | 2025-06-18 tools子集，已有结构Schema，非完整官方SDK/全协议/商业客户端联调 |
| M6 | Recipe/Research不实现，+ask不生成答案 |

本轮全部页面数据来自真实HTTP服务，但浏览器无法直接导航localhost时采用明确的测试桥接。没有改浏览器策略，也没有把这个路径叫作真实部署网址端到端通过。无macOS/Windows实机、容器镜像构建、独立子代理评审。本轮没有访问或修改用户本地Git仓库，不替用户选发布许可证。
