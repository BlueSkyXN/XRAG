# Demo.3 实际范围

**0.7.0-demo.3**，在Demo.2上增量开发，非完整V0.7。查询接口、文件/引用模型和两个程序不重写。

## 本轮实际实现与测试

- 使用概览：真实计数、角色对应视图、五步上手、创建KB入口。
- 保存式模型/后端配置：Embedding/Chat/Rerank/Qdrant/Neo4j，env/file引用、CAS修订、active/desired显示；重启生效，显式配置文件优先。
- 应用Key管理：创建、列表、名称、创建时有效期、停用、最后永久Admin保护、退出会话。一个Key一个身份，不是完整账号目录。
- 反馈：结果表单、分页/状态筛选、原引用阅读、处理说明、修订并发和撤回处理。
- 已发布资料ZIP导出：正文+清单，草稿不进入。
- 数据库快照：创建、列表、下载、删除、SHA256；离线restore仅新目录，旧ref可读但旧Key/自动动作禁用。
- 过期缓存预览/清理：仅临时结果及查询摘要，不删除知识和历史版本。
- CLI：对应管理操作、profile改名/移除/默认选择、新文件下载；明确不存在profile不回退。
- 工作台：实际操作页、帮助、角色控件；手机菜单遮挡在回归中发现并修复。
- Demo.2临时数据原位升级，Demo.3快照到另一目录的恢复，两者分别验证。

保留此前Git固定提交、路径/上传、自动检查、签名Hook、范围/分页/图/知识发布、题集与trace等功能，本轮重跑原程序及页面测试。

## 仍只有受控端点测试

模型、Qdrant、Neo4j和direct后端适配没有真实实例联合运行。保存配置页面不等于这些模型/库完成联调。默认没有fake模型，未配置的语义或Wiki能力明确拒绝。

## 没有扩大的边界

| 项目 | 当前范围 |
|---|---|
| 数据与解析 | MD/TXT、保守标题解析、中文字符/双字词项；非完整YAML/CommonMark，无PDF/Office/OCR |
| 来源 | path/builtin/Git；无OSS/WeKnora、私有Git凭据/LFS/子模块；公共远程分支未现场测 |
| 自动检查 | 秒级轮询/去抖、自定义Hook；不是系统事件/cron或所有云平台原生通知 |
| 用户管理 | Key级应用身份及四角色/KB；无密码账号、多Key归属、组织树、SSO或邀请 |
| 配置 | 保存后重启Server和所有Worker；不热切、不自动同步各进程，不自动重建 |
| 反馈 | 保存与人工处理，不训练、不自动改变排序、不自动入题集 |
| 备份 | SQLite快照；不含外部目录/实际凭据/外部库；恢复限2GiB、新目录 |
| 清理 | 仅过期cache/query_record；历史edition、任务、评测、模型cache仍可持续增长 |
| 模型费用 | 构建/Wiki调用尝试记录保留；无完整Token/金额账务，评测小题集 |
| Wiki | 一次固定Chat生成草稿，未做主题再生成/来源写回；需要实际Chat |
| M6 | Recipe/Research未实现；+ask不生成回答 |
| 运行 | 单机SQLite、Linux实测；非多机集群/生产SLA；Mac需要本机编译未实测 |
| MCP | 固定2025-06-18 tools子集；非全协议/官方SDK/商业Agent现场联调 |

本轮页面采用自身HTML/JS及真实HTTP桥接验证，浏览器策略阻止localhost直接导航；不是完整部署网址E2E。无独立子代理评审结果，不将自审换名。本轮不修改用户仓库、原数据或许可证。
